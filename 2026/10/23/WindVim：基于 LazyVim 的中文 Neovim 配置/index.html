WindVim：基于 LazyVim 的中文 Neovim 配置

WindVim 是基于 LazyVim 的个人定制 Neovim 配置，面向习惯终端开发、希望使用中文界面并结合 AI 编程工具的用户。它沿用 LazyVim 的插件生态、语言支持与快捷键，再加入一套开箱可用的界面与工作区配置。

默认以独立应用 windvim 运行，可以和已有的 Neovim / LazyVim 配置并存，互不覆盖。支持 Linux、macOS，Windows 可通过 WSL 使用。

项目地址：https://github.com/tingfeng347/windvim

特性

  • 中文 / English 随时切换：覆盖快捷键菜单、插件管理、常用选择器和启动页，切换后记住选择；文件内容、路径与命令保留原文。
  • AI CLI 侧栏：通过 Sidekick 接入已安装的 Codex、Claude 等 CLI，支持同一列堆叠多个面板，方便边看代码边协作。
  • 浮动终端与导航：居中圆角终端、文件浏览器、项目搜索、Bufferline 与 Dropbar，沿用熟悉的 LazyVim 操作方式。
  • 完整的视觉定制：Catppuccin 透明主题、Markdown 渲染与专属动态启动页，彩色 W 标识搭配有深度的风环与流动粒子。
  • 配置独立、方便修改：安装时保护已有目录，显式覆盖会先备份；主题、快捷键与本地汉化层都可单独调整。

安装

前置要求：Neovim ≥ 0.11.2（LuaJIT）、Git、rsync。完整依赖见使用说明。

用包管理器补依赖（任选其一）：

从 GitHub 安装：

默认使用独立配置 ~/.config/windvim，安装器不使用 sudo。首次启动会自动下载插件，需要能稳定访问 GitHub；把 ~/.local/bin 加入 PATH 后可直接运行 windvim。

不想用 Git 也可以直接下载源码包：

安装器只复制配置和创建启动器，不自动安装系统依赖；目标目录已存在时会直接停止，只有显式加 --force 才会先备份再替换：

安装器支持 XDG_CONFIG_HOME、WINDVIM_BIN_DIR（默认 ~/.local/bin）和 NVIM_BIN 环境变量。配置目录默认 ~/.config/windvim；数据、缓存和状态使用 Neovim 对应的 XDG 目录下的 windvim 子目录。

启动后建议先跑一遍环境检查：

Copilot 需要单独 :Copilot auth 登录；Sidekick 的 Codex、Claude 等 CLI 需各自安装并登录，可用 :checkhealth sidekick 查看状态。未配置 AI 账号时，文件编辑、导航和汉化功能仍然可用，AI 服务与其订阅不包含在项目中。

快捷键

Leader 键是空格，其余操作沿用 LazyVim 默认快捷键。

功能 快捷键
切换中文 / English <Space>uH
查找文件 / 搜索文本 <Space>ff / <Space>sg
文件浏览器 <Space>e
居中浮动终端 <Space>tp
切换 / 选择 AI CLI <Space>aa / <Space>as
Sidekick 提示词 <Space>ap

启动页动画只更新标识区域，不改动菜单、光标或文件内容；打开其他面板、离开启动页或终端失焦时暂停，小窗口使用静态文字标识。想用静态启动页：

设置 NO_COLOR 时也会停止动画。动画用原生终端字符实现，不需要终端图像协议，也不需要额外插件。

定制时建议改项目目录里的 lua/config/、lua/plugins/ 或本地汉化插件，再 ./install.sh --force 部署；直接改安装目录下的副本，改动会随下次备份一起被搁置。

与已有 Neovim 配置并存

WindVim 靠 NVIM_APPNAME 隔离，不走 ~/.config/nvim，所以不会碰你现有的配置：

内容 路径
配置 ${XDG_CONFIG_HOME:-~/.config}/windvim
数据 ${XDG_DATA_HOME:-~/.local/share}/windvim
缓存 ${XDG_CACHE_HOME:-~/.cache}/windvim
状态 ${XDG_STATE_HOME:-~/.local/state}/windvim
启动器 ~/.local/bin/windvim（可用 WINDVIM_BIN_DIR 改）

卸载

插件、缓存与语言状态可按需单独删除：~/.local/share/windvim、~/.cache/windvim、~/.local/state/windvim。旧的 nvim / lazyvim 配置和备份都会保留。
