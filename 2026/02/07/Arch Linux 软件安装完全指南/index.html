2. AUR (Arch User Repository)

AUR 是社区维护的软件仓库，包含大量官方仓库没有的软件包。

2.1 基本概念

  • PKGBUILD: 构建脚本，描述如何编译和打包软件
  • makepkg: 构建工具，读取 PKGBUILD 并生成可安装的包
  • AUR helper: 辅助工具，自动化 AUR 包的安装过程

makepkg 常用选项

  • -s: 自动安装依赖
  • -i: 构建完成后自动安装
  • -r: 构建后删除构建依赖
  • -c: 清理临时文件

2.4 安全注意事项

  1. 检查 PKGBUILD: 安装前务必检查 PKGBUILD 内容
  2. 查看评论: 阅读 AUR 页面上的用户评论
  3. 验证来源: 确保软件来源可信
  4. 定期更新: AUR 包不自动更新，需手动更新

5.3 通道系统

Snap 使用通道（channel）系统管理版本：

  • stable: 稳定版（默认）
  • candidate: 候选版

  • 占用空间较大
  • 与系统集成度较低

8. 最佳实践

8.1 安装优先级

  1. 官方仓库: 优先使用，稳定可靠
  2. AUR: 官方没有时使用，注意安全
  3. Flatpak/Snap: 跨平台软件或需要沙箱时使用
  4. AppImage: 便携式使用或测试软件
  5. 源码编译: 最后选择，需要特殊配置时使用

8.2 安全建议

  1. 定期更新: 每周运行 sudo pacman -Syu
  2. 检查来源: 安装前验证软件来源
  3. 备份配置: 重要配置文件定期备份
  4. 使用快照: 考虑使用 Timeshift 等工具创建系统快照
