万象大模型与雾凇拼音 Rime 配置指南

万象大模型 + 雾凇拼音 Rime 配置备忘

文件结构

Linux (Arch + fcitx5-rime)

系统数据（由包管理器安装，不要手动修改）：

/usr/share/rime-data/             # 系统级 Rime 数据
├── rime_ice.schema.yaml          # 雾凇拼音方案
├── rime_ice.dict.yaml            # 词库入口
├── cn_dicts/                     # 基础词库（6个）
├── en_dicts/                     # 英文词库
├── lua/                          # Lua 扩展脚本
├── opencc/                       # OpenCC 映射
├── fcitx5.yaml                   # fcitx5 兼容配置
├── default.yaml                  # Rime 全局默认
└── wanxiang-lts-zh-hans.gram     # 万象语法模型 (~400MB)

用户目录（只放自定义内容，优先于系统目录）：

~/.local/share/fcitx5/rime/       # fcitx5-rime 用户目录
├── default.custom.yaml           # 方案列表 + CapsLock + page_size
├── rime_ice.custom.yaml          # 核心补丁（grammar + 简拼 + LLM）
├── rime_ice.dict.yaml            # 词库入口副本（追加 cn_dicts/my）
├── rime_ice.dict.custom.yaml     # 或使用 patch 追加词库（推荐）
├── cn_dicts/my.dict.yaml         # 个人词库
├── rime.lua                      # LLM Translator 入口
├── installation.yaml             # 安装标识（自动生成）
├── user.yaml                     # 用户状态（自动维护）
├── sync/                         # 同步配置
└── build/                        # 部署编译结果（自动生成）

Windows (小狼毫 Weasel)

所有文件都在用户目录，没有系统级目录：

C:\Users\<用户名>\AppData\Roaming\Rime\
├── wanxiang-lts-zh-hans.gram     # 语法模型文件（需手动下载）
├── rime_ice.schema.yaml          # 雾凇拼音方案
├── rime_ice.custom.yaml          # 自定义补丁
├── rime_ice.dict.yaml            # 词库入口
├── default.custom.yaml           # 默认配置
├── weasel.custom.yaml            # Windows 前端皮肤（Linux 用 classicui 代替）
├── cn_dicts/                     # 完整词库（22个文件，手动放置）
├── en_dicts/                     # 英文词库
├── lua/                          # Lua 扩展
├── opencc/                       # OpenCC 映射
├── build/                        # 部署编译结果
├── custom_phrase.txt             # 自定义短语
└── symbols_v.yaml                # v 模式符号

核心区别：Linux 上 rime-ice-git 包将基础数据装到 /usr/share/rime-data/，用户只需在 ~/.local/share/fcitx5/rime/ 放自定义文件。Windows 没有包管理器，所有文件都需要手动放入用户目录。

配置步骤

配置步骤

Linux 安装（Arch / shorin-niri）

  • rime-ice-git 将 schema/dict/lua/opencc 安装到 /usr/share/rime-data/
  • rime-wanxiang-gram-zh-hans 将 .gram 装到 /usr/share/rime-data/
  • 用户自定义文件放在 ~/.local/share/fcitx5/rime/

Windows 准备（小狼毫）

  1. 安装 小狼毫 Weasel
  2. 下载雾凇拼音全部文件放入 %AppData%\Rime\
  3. 下载 wanxiang-lts-zh-hans.gram 放入同目录

通用配置 rime_ice.custom.yaml（全平台适用）

部署

  • Linux: fcitx5 -r 或 rime_deployer --build ~/.local/share/fcitx5/rime /usr/share/rime-data ~/.local/share/fcitx5/rime/build
  • Windows: 右键小狼毫托盘图标 → 重新部署

  1. 部署完成后，尝试删除 wanxiang-lts-zh-hans.gram 文件

验证语法模型是否加载成功：

5.1 注意：.gram 文件位置（已修复）

旧版 rime 编译后在 build/ 目录查找语法模型，需要手动创建软链接。

5.2 注意：default.custom.yaml 中的 grammar 对 rime_ice 无效

default.custom.yaml 里配置 grammar: 只是定义了全局默认语法模型参数，但 rime_ice 引擎流水线中没有挂载 grammar_translator 或 grammar_filter，语法模型不会被实际调用。

语法配置必须在 rime_ice.custom.yaml（schema 专属补丁）中设置，因为 grammar: 配置被写入 schema 后，由 schema 内的 translator（已启用 enable_sentence: true）自动调用。

简单说：default.custom.yaml 的 grammar 段是死配置，删掉也不影响。

5.3 完全重新部署 Rime（踩坑记录，2026-06-24 实测）

整套流程适用于：系统 /usr/share/rime-data/ 被污染、升级后异常、需要完全干净的重新部署。

踩坑总结：

  • rm -rf /usr/share/rime-data/ 会删除所有已安装 rime 包在该目录下的文件，不只是 rime-ice-git 的文件，还包括 rime-prelude 的 default.yaml、rime-essay 的 essay.txt 等。第 6 步必须重新安装这些包，否则部署时找不到基础配置文件。
  • rime_ice.dict.custom.yaml 只放增量内容（如 cn_dicts/my），不要重复系统 rime_ice.dict.yaml 已有的 cn_dicts/8105、cn_dicts/base 等，否则会导致词库条目重复，且 table.bin 编译可能失败。
  • grammar 写法必须用 YAML 块格式： 不能写成 "grammar/language": wanxiang-lts-zh-hans（旧写法，无效）。
  • rime_ice.table.bin 如果用户没有新增 import_tables，rime_deployer 不会重建它，直接复用系统预编译的 58M 版本，这是正常行为。只有添加了额外词库入口时才需要重建。
  • 重启用 pkill fcitx5 && fcitx5 -d 而不是 fcitx5 -r，后者可能不重新加载 .gram 语法模型文件。

8. 主题/皮肤配置（Linux 用 classicui，Windows 用 weasel）

Linux：fcitx5 classicui

fcitx5-rime 不使用 Rime 内部的皮肤系统（weasel.custom.yaml、squirrel.yaml 在 Linux 上无效），界面由 fcitx5 的 classicui 插件渲染。

配置文件：~/.config/fcitx5/conf/classicui.conf

主题目录：~/.local/share/fcitx5/themes/<主题名>/theme.conf

可用主题：

  • default / default-dark — 系统自带
  • fcitx5-material-color — AUR，12 种 Material Design 配色
  • fcitx5-nord — AUR，Nord 风格
  • Matugen — 由 matugen 根据壁纸自动生成

切换后 fcitx5 -r 重启生效。
