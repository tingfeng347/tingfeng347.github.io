基础操作

快捷键 功能
Mod+Q 关闭聚焦窗口
Alt+F4 强制杀死窗口 (kill -9)
Alt+Shift+F4 强制杀死窗口及关联进程
Mod+Escape 切换键盘快捷键抑制
Mod+Shift+E 退出 niri
Mod+Shift+P 关闭显示器 (DPMS)
Mod+Shift+/ 显示快捷键教程

窗口聚焦切换

快捷键 功能
Mod+Left / Mod+H 聚焦左侧列
Mod+Right / Mod+L 聚焦右侧列
Mod+Up / Mod+K 聚焦上方窗口
Mod+Down / Mod+J 聚焦下方窗口
Mod+Home 聚焦第一列
Mod+End 聚焦最后一列
Mod+MouseForward 聚焦上方窗口 (鼠标侧键)
Mod+MouseBack 聚焦下方窗口 (鼠标侧键)
Mod+WheelScrollUp 聚焦左侧列 (滚轮)
Mod+WheelScrollDown 聚焦右侧列 (滚轮)
Mod+O / Mod+G 切换总览界面

窗口/列移动

移动列

快捷键 功能
Mod+Ctrl+Left / Mod+Ctrl+H / Mod+Ctrl+A 移动列向左
Mod+Ctrl+Right / Mod+Ctrl+L / Mod+Ctrl+D 移动列向右
Mod+Ctrl+Home 移动列到最前
Mod+Ctrl+End 移动列到最后
Mod+Ctrl+WheelScrollUp 移动列向左 (滚轮)
Mod+Ctrl+WheelScrollDown 移动列向右 (滚轮)

移动窗口

快捷键 功能
Mod+Ctrl+Up / Mod+Ctrl+K / Mod+W 移动窗口向上
Mod+Ctrl+Down / Mod+Ctrl+J / Mod+S 移动窗口向下
Mod+[ / Mod+A 窗口移入左侧列
Mod+] / Mod+D 窗口移出到右侧列
Mod+, / Mod+Shift+A 合并窗口到当前列
Mod+. / Mod+Shift+D 从当前列弹出窗口

显示器间操作

切换显示器焦点

快捷键 功能
Mod+Shift+Left / Mod+Shift+H 聚焦左侧显示器
Mod+Shift+Right / Mod+Shift+L 聚焦右侧显示器
Mod+Shift+Up / Mod+Shift+K 聚焦上方显示器
Mod+Shift+Down / Mod+Shift+J 聚焦下方显示器

移动列到其他显示器

快捷键 功能
Mod+Shift+Ctrl+Left / Mod+Shift+Ctrl+H / Mod+Shift+Ctrl+A 移动列到左侧显示器
Mod+Shift+Ctrl+Right / Mod+Shift+Ctrl+L / Mod+Shift+Ctrl+D 移动列到右侧显示器
Mod+Shift+Ctrl+Up / Mod+Shift+Ctrl+K / Mod+Shift+Ctrl+W 移动列到上方显示器
Mod+Shift+Ctrl+Down / Mod+Shift+Ctrl+J / Mod+Shift+Ctrl+S 移动列到下方显示器

移动工作区到其他显示器

快捷键 功能
Mod+Shift+Alt+Left / Mod+Shift+Alt+H / Mod+Shift+Alt+A 移动工作区到左侧显示器
Mod+Shift+Alt+Right / Mod+Shift+Alt+L / Mod+Shift+Alt+D 移动工作区到右侧显示器
Mod+Shift+Alt+Up / Mod+Shift+Alt+K / Mod+Shift+Alt+W 移动工作区到上方显示器
Mod+Shift+Alt+Down / Mod+Shift+Alt+J / Mod+Shift+Alt+S 移动工作区到下方显示器

工作区导航

快捷键 功能
Mod+Page_Up / Mod+I 聚焦上一个工作区
Mod+Page_Down / Mod+U 聚焦下一个工作区
Mod+Shift+WheelScrollUp 聚焦上一个工作区 (滚轮)
Mod+Shift+WheelScrollDown 聚焦下一个工作区 (滚轮)
Mod+1 ~ Mod+9 聚焦工作区 1-9
Mod+Ctrl+Page_Up / Mod+Ctrl+I 移动列到上一个工作区
Mod+Ctrl+Page_Down / Mod+Ctrl+U 移动列到下一个工作区
Mod+Ctrl+Shift+WheelScrollUp 移动列到上一个工作区 (滚轮)
Mod+Ctrl+Shift+WheelScrollDown 移动列到下一个工作区 (滚轮)
Mod+Ctrl+1 ~ Mod+Ctrl+9 移动列到工作区 1-9
Mod+Shift+Page_Up / Mod+Shift+I 移动工作区向上
Mod+Shift+Page_Down / Mod+Shift+U 移动工作区向下

窗口布局调整

快捷键 功能
Mod+R 按预设切换列宽度
Mod+Shift+R 按预设切换窗口高度
Mod+Ctrl+R 重置窗口高度
Mod+F 最大化列
Mod+Alt+F 全屏窗口
Mod+Ctrl+F 扩展列占满可用空间
Mod+C 居中当前列
Mod+Ctrl+C 居中所有可见列
Mod+- 减小列宽度 5%
Mod+= 增加列宽度 5%
Mod+Shift+- 减小窗口高度 5%
Mod+Shift+= 增加窗口高度 5%
Mod+Shift+X 切换列标签页模式

浮动窗口

快捷键 功能
Mod+V 切换浮动模式
Mod+N 切换浮动/平铺聚焦
Mod+Shift+V 切换浮动/平铺聚焦
`Alt+`` 切换浮动/平铺聚焦
Mod+Alt+N 切换浮动/平铺聚焦

截图

快捷键 功能
Mod+Alt+A 选取区域截图
Mod+Alt+Ctrl+A 截取聚焦窗口
Mod+Alt+Ctrl+Shift+A 截取整个显示器
Print 选取区域截图
Ctrl+Print 截取聚焦窗口
Shift+Print 截取整个显示器
Mod+Shift+S 截图后编辑 (satty)
XF86Launch1 选取区域截图 (备用)
Ctrl+XF86Launch1 截取聚焦窗口 (备用)
Alt+XF86Launch1 截取整个显示器 (备用)

应用启动

快捷键 功能
Mod+T 共享终端 (kitty –single-instance)
Mod+Return 独立终端 (kitty)
Mod+/ 临时浮动终端 (kitty)
Mod+B 浏览器 (firefox)
Mod+E 文件管理器 (thunar / nautilus)
Mod+Alt+E 文件管理器 (nautilus)
Mod+Z 程序菜单 (dms spotlight / fuzzel)
Mod+P 提取窗口信息
Mod+Alt+O AI 助手 (opencode)
Mod+F1 开关输入法 (fcitx5)
Mod+F2 设置
Mod+F3 录屏
Mod+F5 快速存档
Mod+F8 快速读档
Mod+Alt+W / Mod+Y 壁纸切换
Mod+Shift+F10 随机下载壁纸
Mod+MouseMiddle 关闭窗口 (鼠标中键)

DMS 组件

快捷键 功能
Super+X 电源菜单
Mod+Alt+V 剪贴板
Mod+Shift+N 记事本
Mod+Alt+L 锁屏
Mod+Alt+P 挂起 (关闭显示器 + 锁屏 + suspend)
Ctrl+Alt+Delete 任务管理器
Mod+Shift+W 创建窗口规则

媒体与亮度控制

音量

快捷键 功能
XF86AudioRaiseVolume 增加音量
XF86AudioLowerVolume 降低音量
XF86AudioMute 静音
XF86AudioMicMute 麦克风静音
Ctrl+XF86AudioRaiseVolume 媒体快进
Ctrl+XF86AudioLowerVolume 媒体快退

播放控制

快捷键 功能
XF86AudioPause / XF86AudioPlay 播放/暂停
XF86AudioPrev 上一曲
XF86AudioNext 下一曲

亮度

快捷键 功能
XF86MonBrightnessUp 增加亮度
XF86MonBrightnessDown 降低亮度

侧边栏 (niri-sidebar)

快捷键 功能
Mod+Alt+S / Mod+M 收起/展开窗口到侧边栏
Mod+Alt+Z 展开/收起侧边栏
Mod+Alt+X 反向排序侧边栏
Mod+Alt+R 重置侧边栏窗口位置

其他

快捷键 功能
Ctrl+Shift+R 重命名工作区
Mod+Shift+/ 显示快捷键教程
