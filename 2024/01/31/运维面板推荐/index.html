宝塔面板

点评：国内用户推荐使用宝塔面板，简单好用，并且功能强大，主要的是宝塔面板的免费版就足够我们个人搭建和运维网站了，有精力和时间的可以去学习折腾其它的主机面板。

宝塔Linux面板是提升运维效率的服务器管理软件，支持一键LAMP/LNMP/集群/监控/网站/FTP/数据库/JAVA等100多项服务器管理功能。
有30个人的专业团队研发及维护，经过200多个版本的迭代，功能全，少出错且足够安全，已获得全球百万用户认可安装。运维要高效，装宝塔。

官网：https://www.bt.cn
教程：宝塔面板安装和使用教程汇总
建站：宝塔面板搭建WordPress网站完整教程

1panel面板

1Panel 是一个现代化、开源的 Linux 服务器运维管理面板。1Panel 的功能和优势包括：

  • 快速建站：深度集成 Wordpress 和 Halo，域名绑定、SSL 证书配置等一键搞定；

  • 高效管理：通过 Web 端轻松管理 Linux 服务器，包括主机监控、文件管理、数据库管理、容器管理等；

  • 安全可靠：基于容器来管理和部署应用，最小漏洞暴露面，提供防火墙和日志审计等功能；

  • 一键备份：支持一键备份和恢复，备份数据到各类云端存储，永不丢失；

  • 应用商店：精选各类高质量开源工具和应用软件，助力您轻松安装和升级。

旗鱼云梯

“旗鱼云梯”是一款最新的革命性的SAAS化云端服务器集群运维管理平台，个人及企业用户仅通过 浏览器客户端打开旗鱼云梯云平台即可轻松管理云服务器，以往繁杂地服务器运维操作从此变得简单。

官网：https://www.qyyt.com

旗鱼云梯针对企业运维人员、个人需要分布管理服务器的弊端，帮助企业和个人开发集群管理平台，通过浏览器管理运维集群服务器，使用方便，运维门槛低，普通网络人员学习后即可以运维，帮助企业、个人安全高效的管理服务器。

旗鱼云梯是一款最新的革命性的SAAS化云端服务器集群运维管理平台，个人及企业用户仅通过浏览器打开旗鱼云梯云平台即可轻松管理云服务器，相比以往繁杂地服务器运维操作变得简单。

旗鱼云梯采用云端SAAS化，管理多种公有云、私有云功能，有强大的运维管理功能，提供一站式云主机管理服务。不同厂商、不同区域、不同类型服务器直接导入至旗鱼云梯平台，集群式、统一化操作管理。丰富的软件、工具、插件、建站模板，自由选择，快速部署web运行环境及常用软件服务。不用下载安装Xshell、Putty、SourceCRT等任何服务器登录软件，不用在服务器上键入任何命令行代码，仅打开Windows、 CentOS、Ubuntu、Mac等桌面系统上面的Web浏览器，就可以通过浏览器操作服务器。

针对Linux服务器，支持CentOS，真正集群化管理，一键部署，安全运维，自动维护功能、免费功能：自带LNMP与LAMP、LTMJ快速部署，网站管理，数据库管理，SSL证书，WAF、CC防火墙，SSH防爆破，实时监控信息，文件管理，FTP管理，OSS存储，Linux运维轻松搞定。

服务器日常运维
包括服务器cpu、内存、磁盘、网络、负载、进程等健康状态监控及用户管理，常用软件apache、nginx、mysql、php、ftp等 软件安装， 文件新建、复制、剪切、重命名、编辑、上传、下载等操作，以及常用的定时任务、命令行终端，网站及数据库 日常管理维护，SSL证书签发，WAF防火墙等。

网站或Web应用搭建及运维
一键自动化部署LNMP、LAMP等Web运行环境，支持多种软件版本自由选择及切换，完备可靠的网站、数据库等运维管理操作。

服务器集群集中管理
支持阿里云、腾讯云、百度云、华为云、网易云、京东云等主流厂商服务器一键导入平台，及IP直接导入平台，一个旗鱼云梯 账号就可以实现不同 厂商不同区域的服务器集中化、统一化管理。

URLOS面板

LuManager(LUM)是基于FreeBSD、Debian、Centos、Ubuntu、HttpOS等Linux/Unix系统的网站服务器管理软件，是目前国内市场上为数不多的同时支持Linux和Unix的网站服务管理软件（好像是唯一的？）。只要您会上网，就可以搭建和管理Linux/Unix服务器！完美支持Discuz、Phpwind、Shopex、ECShop、Ecmall、Wordpress、Dedecms、PHP168、PHPCMS、ECMS、CmsTop、Zen-Cart、Xweibo、Iweibo等常用php+mysql结构程序。还集成了常用程序的快速安装方法，安装好LuManager后，5秒内即可创建一个网站！使创建网站的门槛大大降低。LUM是从已经有6年历史的FAMP分离出来的控制面板的升级版本，我们将其命名为LuMananger，即Linux/Unix的管理者，简称LUM。

官网：https://www.urlos.com/docker/thread-47148-1-1.html

LuManager已经停更，现在使用 URLOS -让你轻松构建网站运行环境

WDCP

wdcp是一款免费的Linux服务器云主机管理系统，通过wdcp可在线WEB方式轻松管理Linux服务器系统和数据,网站，数据库，FTP，应用配置，应用服务等

1 可一键快速部署lnamp,lamp,lnmp等WEB应用环境,支持tomcat,nodejs等应用
2 支持N+A的组合模式，支持多PHP版本共存和选择切换等
3 站点创建，域名绑定，二级域名，伪静记，HTTPS支持，301跳,404重定向等
4 mysql数据库创建，用户创建与设置
5 FTP帐号的创建与管理
6 系统管理，资源流量,系统日志，IP设置，进程管理，服务管理，端口管理等
7 安全设置,禁PING，SSH端口与密钥设置，selinux设置，Iptable防火墙的增加与设置
8 数据备份，可在线打包文件或目录，站点文件或数据库
9 计划任务，可创建与自定义一些定时定期执行的任务或程序
10 文件管理器，在线编辑，文件下载，移动，打包，远程下载等

官网：https://www.wdcp.net/service.html

cPanel

cPanel虚拟主机管理系统功能强大，cPanel是一套基于Web的自动化hosting管理软件，构建于LAMP环境之上，主要应用于PHP语言。

对虚拟主机有一定了解的站长，基本上都听说过Cpanel控制面板，它也是整个行业类被模仿的对象。功能不仅强大，管理起来也十分简捷。不过它的价格也相对比较贵，它在国外的用户群体非常广泛。

站长作用Cpanel，几乎可以控制所有内容，有一定知识基础的，甚至都不用为功能的开通而去联系客服或者主机商，这个强大的控制面板能够解决几乎所有的问题，倘若有做不到的功能，也极有可能是程序不适应虚拟主机环境。当然，这么强大的虚拟主机控制面板，价格也非常贵。国内提供Cpanel面板的主机也很少，不过技术在发展，市场也在完善，国内也出现了很多Cpanel经销商，也基本上能够提供相关的服务。

Vestacp

官方网站： https://vestacp.com

1、Vestacp是由俄罗斯的人编写的VPS主机控制面板，支持中文，部落用过之后第一个感觉就是Vestacp功能强大，支持Apache、Nginx、Bind、Exim、Dovecot、vsftpd、MySQL等，提供可视化的网站管理面板。

2、Vestacp功能强大，可以和WHMCS搭配使用，同时也可以直接使用Vestacp构建一个独立的DNS管理系统。如果你只是一个人使用的话，也完全可以使用Vestacp多账户管理系统，让多人共享使用一个VPS主机。

  • Vestacp免费VPS主机控制面板:功能强大免费邮局轻松搭建网站

  • Vestacp整合WHMCS实现自动销售开通虚拟主机服务

DirectAdmin

DirectAdmin是一款功能强劲的虚拟主机在线管理系统，具有设置EMAIL、设置DNS、开通FTP、在线文件管理、数据库管理等功能。

目前恒创科技提供的新云主机就是使用的DirectAdmin管理面板。

Plesk控制面板

Plesk是款国外开发，支持中文，且同时支持Linux和windows服务器管理面板，款主机自动化解决方案，可以帮助主机商实现对托管的Web主机服务器的全面控制，并简化了用户账户、网站和电子邮件账户的设置和管理。被广泛的用于管理虚拟主机和独立主机。它丰富的工具套件能够帮助用户快速进行数据迁移，不但易于操作，而且可以小化宕机时间。获得坚若磐石，稳定高效的美誉。

Kloxo-MR

Kloxo-MR 基于Kloxo优化的开源主机系统

官网： http://mratwork.com
源码：https://github.com/mustafaramadhan/kloxo/
教程：https://wzfou.com/kloxo-mr

Kloxo-MR是一个开源的服务器控制面板，可用于Redhat / CentOS 5, 6 和 7系统创建和管理虚拟主机，从名字可以看出Kloxo-MR是基于Kloxo改良过来的，只不过Kloxo-MR在性能上还有功能上都做了不少的改进，便得用起来更加顺手。
Kloxo-MR支持切换Web服务器，支持Nginx、Lighttpd、Hiawatha和Apache等自由切换，新版支持Squid，Varnish和ATS（Apache Traffic Server）。默认支持PHP 5.3 、5.4，不过在Kloxo-MR 7.0中已经可以自由选择PHP版本了。

CyberPanel

CyberPanel是一个基于OpenLiteSpeed开发的服务器控制面板，支持LSCache高性能缓存，提供免费letsencrypt SSL证书，可以一键签发SSL证书，CyberPanel支持自建DNS服务器，可以一键安装PowerDNS，你可以用它搭建DNS服务器。

官网： https://cyberpanel.net

脚本安装包

LNMP

LNMP一键安装包: https://lnmp.org

LNMP一键安装包是一个用Linux Shell编写的可以为CentOS/RHEL/Fedora/Aliyun/Amazon、Debian/Ubuntu/Raspbian/Deepin/Mint Linux VPS或独立主机安装LNMP(Nginx/MySQL/PHP)、生产环境的Shell程序。https://lnmp.org/， 很多其它面板上支持一键安装lnmp，比如宝塔, 一直都是由“军哥”开发和运作。

  • 1、LNMP.org 提供的LNMP一键安装包，是一个用Linux Shell编写的可以为CentOS/RadHat/Fedora、Debian/Ubuntu/Raspbian/Deepin VPS或独立主机安装LNMP(Nginx/MySQL/PHP)、LNMPA(Nginx/MySQL/PHP/Apache)、LAMP(Apache/MySQL/PHP)生产环境的Shell程序。

  • 2、LNMP.org 提供的LNMP没有面板，但是有不少的实用建站功能，如：虚拟主机管理、FTP用户管理、Nginx、MySQL/MariaDB、PHP的升级、常用缓存组件Redis、Xcache等的安装、重置MySQL root密码、502自动重启、日志切割、备份等许多实用脚本。

  • 3、LNMP.org 提供的LNMP一键安装包在国内的知晓度非常高，拥有用户众多，同时网上关于LNMP的教程不少，方便大家解决操作中的问题。再加上面提供的各种实用的建站小工具，所以说LNMP.org 的LNMP安装包足以胜任建站了。

LAMP

官网 https://lamp.sh/ ，由泰迪大佬编写及运作，是一个用 Linux Shell 编写的可以为 Amazon Linux/CentOS/Fedora/Debian/Ubuntu 系统的 VPS 或服务器安装 LAMP(Linux + Apache + MySQL/MariaDB/Percona + PHP) 生产环境的 Shell 脚本。

LANMP

官网： https://github.com/wangyan/lanmp

  1. LANMP 指的是 Linux + Apache + Nginx + MySQL + PHP 运行环境。

  2. LANMP 一键安装包是用 Linux Shell 语言编写的，用于在 Linux 系统(Redhat/CentOS/Debian/Ubuntu)上一键安装 LANMP环境的工具包。

OneInStack面板

官方网站： https://oneinstack.com/

官网 https://oneinstack.com 作者个人开发，持续不断更新，支持交互、无人值守安装，包含了以下组合：LNMP、LAMP、LNMPA、LNMT、LNPP、LNMH。源码编译安装，大多数源码是最新stable版，并从官方网址下载

  • 1、OneinStack的一键LNMP安装包与lnmp.org站长开发的LNMP一键安装包最大的不同之处就是，多出了支持lnmt（Linux + Nginx+ MySQL+ Tomcat）：Nginx处理静态，Tomcat（JDK）处理JAVA和lnmh（Linux + Nginx+ MySQL+ HHVM）。

  • 2、OneinStack最大优势就是更新速度快，目前已经增加PHP7.1、PHP7支持ioncube、apcu，支持自动部署Let’s Encrypt免费证书，php-7.0支持redis、memcached、imagick扩展插件。所以想要体验PHP 7的话可以选择OneinStack。
