浏览器插件推荐

Microsoft Edge是由微软开发的基于 Chromium 开源项目及其他 开源软件的网页浏览器**。**

2021年5月19日，微软宣布IE浏览器将在次年退出市场，2022年6月15日，大多数版本的Windows 10系统不再支持IE浏览器，取而代之的是更新、更快、更安全的Edge浏览器。微软在浏览器方面主推Edge，这款产品于2015年启用，与谷歌旗下的Chrome浏览器基础技术相同。微软建议仍在使用IE的用户在2022年夏天之前更换浏览器。

Microsoft Edge 浏览器为微软官方一款自带的浏览器，相比于早已淘汰的IE浏览器，其功能更加强大。采用与chrome、火狐相同的Chromium内核。尤其是强大的同步和扩展功能。

Edge支持windows、macOS、iOS、Android多端同步，支持浏览记录、收藏夹、密码等通过账号同步，甚至还有发送网页从手机到电脑的强大功能。在手机上不方便查看的网页或者没看完的网页，可以直接发送到电脑端查看。当然，这一切的前提是需要登陆相同的微软账号。

自从Edge浏览器采用谷歌Chromium内核上线以后，越来越多的国内用户转投Edge浏览器麾下。原因无他：国内用户可以直接访问edge浏览器的插件商城，不用像goole Chrome 那样要先连上外网。

今天从众多浏览器插件中整理了16款神级且实用的插件，插件里包含了一键屏蔽垃圾广告、快速复制文字、图片助手、快速下载等插件，让你的浏览器瞬间开挂！

✓ 文档转换器 (pdf 到 jpg, doc 到 jpg, …)
✓ 电子书转换器 (epub 到 pdf, epub 到 mobi, …)
✓ 图片转换器 (png 到 ico, png 到 jpg, …)
✓ 演示文稿转换器 (ppt 到 pdf, ppt 到 jpg, …)
✓ 视频转换器 (mkv 到 mp4, mov 到 mp4, …)

✓ OCR（识别文本, 光学字符识别）工具

Infinity 新标签页 (Pro)

全球上百万用户选择的最佳新标签页，功能包括：网站图标，搜索引擎，高清壁纸，书签管理、天气、笔记、待办事项、扩展管理、历史记录等。Infinity新标签页 (Pro) 是一款基于html5开发的扩展程序，它能够替换浏览器的起始页与新标签页，提升其美观性与生产力。

Infinity 新标签页这款插件，就是专门用来打造浏览器起始页面的，它可以实现：网页快捷链接、不同搜索引擎、背景图片、账户备份和还原等。

功能介绍：

1、网站图标：轻松访问常用网站。在新标签页上单击网站图标即可快速导航到常用网站，我们提供了上千个热门网站的图标，您也可以选择自定义添加，并调整图标的大小、颜色、布局等。此外，还能使用文件夹来对网站图标进行分组管理。

2、高清壁纸：轻松更换精美高清壁纸。内置多个精选高清壁纸源，支持一键随机切换、自动更新。您也可以上传本地图片作为壁纸，并按照您的喜好调节模糊度、遮罩浓度。

3、搜索引擎：多款热门搜索引擎（Google、百度、Bing等）供您一键切换，您也可以自行添加其他搜索引擎以及附加搜索引擎，大大提高搜索效率。

4、云同步：使用邮箱账号或第三方账号（Google、微信、微博、QQ）登录后，可自动或手动备份数据到云端，再也不必担心数据丢失与账号同步问题。

5、天气：自动获取您所选城市的天气，并在图标上实时反馈。可添加多个城市的天气情况，支持查看多日天气预报以及风力、气压等信息。

6、待办事项：随时记录和查看您要做的事和做过的事，图标上会出现未完成事项数量的角标提示。

7、笔记：快速记录您当下的灵感和生活点滴，支持插入图片和超链接。

8、书签：简洁的书签侧边栏，以便您管理和访问浏览器上保存的书签。

9、历史记录：无需跳转历史管理页面，直接在侧边栏中查看、搜索、清理浏览器历史记录。

10、扩展管理：直接在侧边栏中查看、启用、禁用、卸载浏览器当前已安装的扩展程序。

11、Gmail邮件通知：通过新标签页提供的Gmail图标关联您的邮箱账号，图标上会实时显示未读Gmail邮件数量，并伴有声音提醒。

12、支持多种语言：我们适配了33种语言以满足全球不同地区用户的需求，在使用过程中无需担心语言上的障碍。

现在安装Infinity新标签页 (Pro)，就能免费体验便捷的功能、漂亮的界面，将浏览器主页及新标签页打造成您的最佳生产力工具。

直达链接：https://microsoftedge.microsoft.com/addons/detail/infinity-%E6%96%B0%E6%A0%87%E7%AD%BE%E9%A1%B5-pro/hajlmbnnniemimmaehcefkamdadpjlfa?hl=zh-CN

图片助手(ImageAssistant)

是一款运行于chromium(chrome环境下开发)及其衍生浏览器(如：360安全浏览器、360极速浏览器、猎豹浏览器、百度浏览器、UC浏览器等)提供分析、提取网页中的图片并以多种筛选方式辅助用户选取下载等功能的浏览器扩展软件（提供分析、提取网页中的图片并以多种筛选方式辅助用户选取下载等功能）

不同于以往提供类似功能的浏览器扩展，本扩展融合了多种数据提取方式来保证在各种复杂结构页面中尽可能全面地提取到出现过的图片。

直达链接：https://microsoftedge.microsoft.com/addons/detail/图片助手imageassistant-批量图片/odphnbhiddhdpoccbialllejaajemdio

Global Speed: 视频速度控制

与几乎所有视频和音频流媒体站点兼容，包括Youtube，Netflix，哔哩哔哩，腾讯视频，百度网盘， 爱奇艺等。自定义播放速度，最大支持16倍倍速。

这是一个功能精简、轻量型的哔哩哔哩播放器扩展。播放器功能选项：∙ 启用(扩展添加的)快捷键功能。∙ 空格键始终用于播放/暂停（而非页面向下滚动）。∙ 默认关闭弹幕。∙ 自动播放。∙ 播放结束时自动退出全屏。∙ 屏蔽底部弹幕(防挡字幕)。∙ 默认关灯。∙ 上下滚动时自动开灯关灯。∙ 默认显示模式：正常、宽屏或网页全屏。

ITab 是一个免费的，无广告的，强大的新TAB插件，具有高级的级别，但大小仅仅只有5 MB。iTab是一个好看好用的自定义卡片式浏览器新标签页扩展。安装iTab标签页扩展后，您将告别呆板无趣的原生标签页，享受iTab标签页为您带来的个性化新体验

OneTab

当您发现自己有太多的标签页时，单击OneTab图标，将所有标签页转换成一个列表。当您需要再次访问这些标签页时，可以单独或全部恢复它们。

当您的标签页位于OneTab列表时，您将节省高达95％的内存，因为你将减少Edge浏览器中打开的标签页的数量。

直达链接：https://microsoftedge.microsoft.com/addons/detail/onetab/hoimpamkkoehapgenciaoajfkfkpgfop?hl=zh-CN

一个油猴插件，可以抵得上几十款插件，尤其是那些各种各样的脚本，简直太神奇了，可以实现各种不同的功能。
